# How to replay a trace

- Make sure JavaScript is enabled in the browser.

- Go back to the initial state, either by:

    + clicking the first `Target State ID` button in the `Trace` section, or

    + repeatedly clicking `Back` in the `Replay Trace` section.

- Go to the next state, either by:

    + clicking the next `Target State ID` button in the `Trace` section, or

    + clicking `Forward` in the `Replay Trace` section.

The panels give information on the values of variables, the enabled events, the
invariants, etc.
